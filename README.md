# 💈 Gerenciador de Barbearia

Sistema web de agendamento online para barbearias. Substitui a agenda de papel e o agendamento manual pelo WhatsApp, reduzindo faltas e cancelamentos de última hora.

## ✨ Funcionalidades planejadas

- [ ] Página pública de agendamento (serviço → barbeiro → horário)
- [ ] Painel administrativo com agenda do dia/semana
- [ ] Cadastro de serviços, barbeiros e horários de trabalho
- [ ] Bloqueio de horários (folgas, almoço)
- [ ] Lembretes e confirmação automática via WhatsApp
- [ ] Lista de espera para horários cancelados
- [ ] Sinal via Pix para reduzir faltas
- [ ] Histórico de faltas por cliente
